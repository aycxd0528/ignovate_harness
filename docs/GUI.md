# Ignovate GUI

PRD：[飞书 PRD v0.2](https://qcnvafay57br.feishu.cn/wiki/NSDnwv74PiTwrlkSISScV3aYnyf)。macOS 已进行 Electron 与 Chrome 验证，Apple Silicon 可使用内置 Python 的 DMG 桌面安装包；当前为本地签名，Developer ID、公证、Intel Mac 与 Windows/Linux 桌面安装包留在后续阶段。

## 启动

本项目已有 `.venv` 与 Electron 依赖，可直接运行：

```sh
.venv/bin/python -m nailong.gui --project /path/to/project
```

安装 Python 包后也可使用 `ignovate gui --project /path/to/project` 或 `ignovate-gui --project /path/to/project`。源码目录有 Electron 时优先打开桌面窗口；否则打开本机浏览器。显式使用浏览器：

```sh
.venv/bin/python -m nailong.gui --browser --project /path/to/project
```

GUI 从本地服务页面加载，启动器会自动打开带本次连接凭据的 URL。直接打开 `nailong/gui/static/index.html` 会显示启动说明；静态 HTML 自身无法运行 Python 内核。浏览器地址应为 `http://127.0.0.1:<端口>/`。

连接时显示光点汇聚与品牌字样逐渐清晰的启动动画，至少展示 2 秒，且首次原生快照成功后才进入工作台；连接超过 2 秒时不会额外等待。连接失败会立即显示原因及“重新加载”。启动页沿用已保存的外观，支持系统“减少动态效果”。思考状态使用轻微呼吸与文字扫光，工具记录仅在首次出现时淡入；流式文字和工具状态更新保留已有正文、展开状态与滚动位置。

新机器安装桌面依赖：

```sh
npm --prefix desktop ci
npm --prefix desktop run install-electron
```

Python 沿用项目已有安装流程。`IGNOVATE_PYTHON` 可指定桌面使用的 Python 可执行文件。`IGNOVATE_EDITOR` 可指定文本编辑器可执行文件，作为单独 argv 调用；默认 macOS 使用 TextEdit，Windows 使用 Notepad。Linux 需指定编辑器。关闭窗口会先取消并清理内核运行，然后关闭本机服务。

## 使用

- 界面采用蓝色品牌文字与强调色，其余使用黑白灰。左栏直接按工作区显示目录与会话；支持工作区分组、工作区树、单列表，最近更新或手动排序，以及归档筛选。目录可折叠，目录旁可新建会话，会话右侧显示更新时间；另有插件、搜索、添加工作区和设置；顶栏的 SVG 按钮控制左侧栏、详情栏和主题，主题按钮位于详情栏开关右侧，默认跟随系统。窄窗口的侧栏可从栏内关闭。侧栏展开时隐藏顶栏的同类按钮，收起后才显示展开入口。
- 会话标题右键、Shift+F10 或右侧更多按钮打开菜单，可重命名、归档/恢复、设为主分支、导出及手动上下移动。Escape 关闭菜单并返回原控件。API Key 只由 Python 内核保存，GUI 加载配置时不返回密钥；取消设置不保存。模型设置中的测试连接会发送一次模型请求，可能计费。
- 中栏选择聊天、会话地图或轨迹；输入框默认紧凑单行，多行内容自动增高，最多 160px 后在框内滚动。左下角“＋”菜单包含项目文件/文件夹引用及实施、计划、只读审查、目标模式，旁边为权限管理。完全访问使用适配主题的橙色。模型与推理强度合为一个胶囊入口：打开强度面板后，点击中央模型名称进入模型列表，可新增模型或打开连接设置。新增模型沿用当前提供商连接，名称/ID 保存到原生项目偏好；切换模型恢复默认推理强度。菜单随浅色/深色主题适配；SVG 按钮在鼠标悬停和键盘聚焦时显示名称。权限模式按分支隔离，入队时捕获；新分叉默认请求批准，不继承临时模式和审批。首次设置权限自动创建会话并保留未发送草稿。Enter 或发送图标发送，Shift+Enter 换行，中文输入法确认不会发送。引用文件或选中文字追问先进入草稿。
- 目标模式沿用原生 GoalStore/drive_goal，启用时填写轮次与费用上限，发送后才开始任务；模型需有价格配置。地图发送采用相同限制。停止后显式恢复沿用原目标与剩余预算，暂停原因显示在状态栏。
- 推理等级面板参考 dsh-effort-slider：连续拖动，松手或结束键盘调节时吸附到真实档位并保存；轨道用蓝色 WebGL 火焰/辉光跟随滑块。请求串行执行且合并重复手势；关闭面板后不会提交积压的旧选择。模型不支持分级推理时只显示默认，不虚构 provider 能力。减少动画时静态绘制；关闭、隐藏或 GPU 不可用时停止动画并保留可用控件。BSD-3-Clause 着色器来源及完整上游声明位于 `nailong/gui/static/EFFORT-LICENSE.md`。
- 用户输入在右侧气泡显示，模型正文在左侧展开；状态与处理时间位于正文上方，用量、时间和 SVG 操作位于正文下方。新会话默认用首次用户输入命名，手动名称和分支名称会保留。
- 完全空白的新会话在离开或重新打开应用时自动清理；重复新建会复用当前空白窗口。聊天草稿、地图追问草稿、发送记录、任务、检查点和已有分叉均会保留；从未发送的新工作区会在首次输入文字时保存草稿。
- 桌面端复制回答、输入和代码块通过校验来源的原生剪贴板通道写入，不依赖网页剪贴板权限；浏览器版使用浏览器剪贴板接口。写入成功后提示“已复制”。
- 标注语言的 Markdown 代码块使用随包分发的语法高亮，适配浅色、深色和系统主题。未知或未标注语言保持纯文本；复制保留原始代码。代码字体优先使用 Consolas、Cascadia Mono，字号为 14px、行高 1.65，改善 Windows 上的可读性；字体不可用时使用系统等宽字体。
- 输入框上方显示当前会话等待发送的消息，可直接编辑、保存、取消编辑或删除；保留原有顺序和任务模式。后台刷新不会清除正在编辑的文字，编辑不影响输入框中的新草稿。已经开始执行的消息不能修改；删除等待消息不暂停正在执行的任务。
- 失败或停止后，若等待队列为空，再次明确发送的新消息会直接开始新任务。若还有旧消息等待，则保留暂停并显示“等待恢复”，需显式恢复后才发送；暂停的等待消息不会被显示成正在运行，也不会将发送按钮变为停止按钮。
- 回答渲染 Markdown 标题、列表、强调、引用、代码和表格；代码支持复制。原始 HTML 作为文字显示，链接仅允许 HTTP/HTTPS。解析器为本地随包分发的 Marked 17.0.5（MIT，许可证在 `nailong/gui/static/MARKED-LICENSE.md`），不依赖 CDN。
- 状态栏的 Token Weather 沿用内核的上下文占用、天气等级和趋势，以最近一次主模型请求输入用量为准；子代理用量不计入主上下文。累计计费用量单独显示，缺少 usage 时保留未知状态。
- 模型调用工具时只保留一条实时状态，展示当前命令或文件名称；并行调用显示同时处理的数量。工具完成后继续保留该行，直到整项任务结束或停止，再收为“调用了工具”，可展开查看完整输出和文件变更。等待批准仍显示审批提示。任务用时从真正开始执行计时，不含排队时间；完成/停止后的时间保存并保持固定，旧日志缺少时间时显示未知。工具结果和审批显示所属运行。停止会等待内核清理，队列暂停；可移除排队任务或显式恢复。重启后中断运行不会自动重放工具；尚未开始的任务保留原输入和模式。
- 已完成的可恢复回合支持分叉、编辑和重新生成。新分支只继承该边界之前的模型与任务状态，压缩历史按引用复制给新分支。缺少 checkpoint、工具未闭合或历史归档截断时拒绝精确分叉。
- 地图以新会话为起点，使用画布内的提问卡片输入第一个问题；卡片侧边的加号继续追问，分支图标打开虚线连接的新分支草稿。选中文字后可引用追问，并有常用补充词。发送后的提问卡片保留位置并显示运行状态、工具活动和模型内容，完成后转成回答卡片。卡片与草稿连线随拖动实时更新，运行状态更新不会打断拖动；每张回答卡片可独立滚动，详情在右侧阅读；聊天页的详情仍展示产物。地图只显示当前会话及其分叉路径，按真实回合的父子关系呈现探索流程；不混入项目中的无关会话。支持拖动卡片标题或手柄、平移、最高 4× 缩放、折叠、定位、整理布局和列表导航。布局按会话保存，同一会话的连续更新依次提交；整理布局不会删除历史。聊天初次显示末尾 80 个回合，可加载更早内容；从地图定位早期回合会加载目标。
- 轨迹按当前分支的真实轮次显示用户输入、助手输出、模型阶段与工具执行。顶部显示用时、轮数和模型/工具调用数；输入、模型、工具三条概览按事件顺序排列，点击片段定位并展开相应事件。支持搜索、展开参数预览和执行结果；运行更新保留搜索、展开状态与位置，完成后保留历史。默认展示最近 80 轮，可加载到最近 500 轮；更早内容仍保存在会话日志。轨迹中可继续发送消息或处理批准。
- ⌘/Ctrl+N 新建当前工作区会话；⌘/Ctrl+K 打开操作入口，包含环境检查、当前工作区与验证；⌘/Ctrl+F 查找当前路径，地图手柄支持方向键移动。主题在系统、浅色、深色之间切换。
- 详情栏展示实际记录的文件、命令结果与验证报告，并保留工具过程、用量和来源；模型正文在主聊天区查看。文件/diff 均标为当前共享工作区；选择历史或分叉不会撤销文件操作。验证后再次修改输入文件会显示证据过期。
- 导出包含选定路径、来源和脱敏后的记录。界面已移除比较入口。

## 项目任务与工作控制

会话地图新增「项目任务、关注事项、阶段回执、反馈经验」四个入口。项目任务按稳定 task_id 关联到当前会话，共用要求和验收；任务步骤依赖单独显示，画布连线继续表示会话上下文。关注事项可解除明确等待、填写人工检查结果或打开原生审批。过期的人工确认会重新出现，操作按要求修订校验。

持续目标在下一轮模型调用前判断继续、等待、重核计划或停止，并展示基于当前证据的进展。明确等待不会启动新模型轮次；条件满足后解除等待，再显式恢复目标。阶段回执从该次运行的原生来源核对已写阶段，重启不会自动重放工具；缺失副作用结果、用量或价格时显示未知。

反馈先整理为候选，用户确认后写入现有项目记忆，保留来源、输入版本与失效边界；可撤销，经验不代替测试或授予权限。CLI 使用 `/task list`、`control`、`link`、`wait`、`ready`、`feedback list|confirm|revoke` 查询或操作同一份状态。详见 [六项机制整合报告](reviews/2026-10-14-loopx-map-optimization-report.md#10-实施结果与使用方法2026-10-15) 和 [本次验收记录](reviews/2026-10-15-loopx-control-map-implementation.md)。

## 插件管理

左栏的「插件」页显示当前项目与用户目录中的原生 Skills，以及项目 MCP 服务。列表显示实际启用状态、来源、连接状态和工具数量。

- 添加本地 Skill：选择包含有效 `SKILL.md` 的目录，安装到项目 `.agents/skills/<name>`；同名目录不会被覆盖，不执行安装脚本。启停沿用内核项目偏好，下一次任务使用更新后的目录。
- 添加 MCP：填写服务名称与原生 JSON 声明；支持 `stdio` 或 HTTP，`env` / `headers` 只能使用 `${ENV_NAME}` 引用。保存配置不会启动服务。连接/断开使用实际内核管理器；修改已连接服务前需先断开。
- 移除 MCP 会断开连接并移除当前项目的声明。任务运行或排队期间可查看插件，修改需要等任务结束。未连接服务与不可发现 Skills 的诊断保持可见。

## 数据与执行边界

内核仍为 `AgentService`，GUI 没有第二套模型或工具循环。一个 Python 异步事件循环拥有模型、SQLite 和 MCP 生命周期；Electron 只负责窗口、项目选择和文本编辑器桥接。HTTP 服务仅监听 127.0.0.1，要求每次启动的随机令牌并校验 Host/Origin；渲染器禁用 Node，启用 sandbox/context isolation。模型调用会发送到用户配置的提供商。

数据沿用 `ProjectSessionStore` 的项目路径隔离。新增：

| 文件 | 内容 |
| --- | --- |
| `branches.sqlite` | 分支关系、回合边界、每个回合一份不可变事件来源、运行和幂等请求 |
| `gui-layout.sqlite` | 按会话保存的卡片位置、视口、折叠与按分支保存的草稿 |
| `project-execution.lock` | CLI/GUI 共用的跨进程执行锁 |

共享祖先通过节点 ID 引用，不复制到每个子分支日志；不可变事件来源保证 CLI 回退不会改写子分支已继承的记录。新 CLI 回合会同步展示。导入的旧会话若仍有与末轮问答一致的完整、终态 checkpoint，可在原窗口继续；发送与实际执行前都会再次核对。继续会话不代表旧回合可以精确分叉，缺少原始绑定的历史节点仍保留分叉限制。缺少检查点、工具交换未闭合或记录不一致时显示具体原因，并保留基于摘要新建的入口。CLI 改写已索引日志时保留 GUI 来源并禁用不可信的续接。fork 不继承目标预算、执行锁或临时会话审批规则。

失败任务会保留异常类型、原因及可用的 HTTP 状态和请求标识，展示前隐藏已配置的密钥。即使异常没有文字，也会显示类型和说明。长时间闲置后若再次出现失败，可复制底部的错误详情用于定位；不会自动重放已执行的工具操作。

从源码运行时，如果应用运行期间 Python 代码发生更新，会提示退出并重新启动 Ignovate。新任务入队和实际执行前均检查代码版本，避免旧内存模块与新源码混用。切换工作区或刷新页面不会绕过此检查；源码版本检查随内核进程保留，项目文件和配置的正常修改不会触发重启要求。
