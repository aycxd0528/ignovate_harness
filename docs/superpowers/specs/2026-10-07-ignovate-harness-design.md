# ignovate harness 启动与运行设置

将产品显示名称统一为 `ignovate harness`，提供 `ignovate` 主命令，保留现有 Python 包、`.nailong` 项目数据及 `nailong` 命令兼容，已有会话不迁移。

首次交互启动展示欢迎、当前项目和使用提示，提供 API 地址、模型 ID、隐藏输入的 API Key、推理强度及三档权限选择。已配置密钥留空保留。用户确认后才保存；取消不写配置、不启动 Agent。再次启动直接进入会话，`--setup` 重开指引。无头模式及非终端输入不弹欢迎，缺失配置时提供配置命令。

用户专用模型连接配置存入 `~/.ignovate/config.json`，原子写入、权限 0600；不进入项目、会话或运行轨迹。显式用户连接配置优先于原 `.env`。推理设置仍支持项目/用户偏好和 CLI 覆盖。正常首次引导沿用已有连接信息，不自动发送 API 请求。

推理强度采用 DeepSeek 官方实际档位：默认、关闭、低、高、最高，对应 `default/none/low/high/max`。已知 V4 模型可设置，未知模型只开放默认并解释原因。真实请求带 `reasoning_effort` 与正确的 thinking 开关；主代理和子代理一致。不能把推理强度实现为增加工具调用轮数。

权限标签和内部模式：请求批准=`default`；帮我批准=`acceptEdits`（文件修改自动批准，命令仍询问）；完全访问权限=`bypassPermissions`（任意文件路径与网络目标，不逐项审批）。权限仅本次进程有效，不持久保存完全访问。只读计划、审查、子代理和文件版本检查继续有效。

新增 `/reasoning` 与可选择模式的 `/permissions`，TUI 用底部紧凑选择面板，inline/plain 用同一组选项；裸 `/permissions` 同时保留规则说明。设置在请求队列边界执行，下一轮使用新值；切换项目仍继承本次权限。状态区域显示实际推理设置和权限。

自审：旧数据不破坏；新命令可实际运行；密钥不回显；取消无落盘；完全访问不跨启动；未知模型不发送虚构参数；新模型与推理组合先校验再保存；权限切换同步运行时和 UI。
