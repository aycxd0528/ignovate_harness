# Ignovate GUI Implementation Plan

> For agentic workers: use executing-plans and test-driven-development; retain the existing working tree changes.

**Goal:** Implement the PRD's local GUI and nonlinear conversation workflow using Ignovate Harness.

**Architecture:** A Python loopback adapter owns AgentService, lifecycle, authentication and commands. Kernel branch metadata indexes original JSONL events and immutable checkpoint references, with a separate SQLite database for layout/drafts. An Electron shell displays the same dependency-free web UI, with narrowly scoped native directory/editor actions.

**Tech Stack:** Python 3.11+, existing LangGraph SQLite saver, SQLite, standard-library HTTP, browser ES modules, Electron.

**Spec:** [Feishu PRD v0.2, revision 60](https://qcnvafay57br.feishu.cn/wiki/NSDnwv74PiTwrlkSISScV3aYnyf); fetched 2026-10-11.

## Global Constraints

- Ignovate remains the sole model/tool/permission/usage/validation backend. No competing agent loop.
- P0 shared workspace runs serialize across CLI and GUI. Selecting or forking history never restores files.
- Fork only complete recoverable boundaries, including closed tool exchanges and task snapshots. No automatic replay after failure.
- Ancestors are referenced, not charged twice. Layout and drafts do not alter model inputs.
- Legacy history without recoverable state remains readable; no invented recovery promises.
- Local service binds 127.0.0.1, rejects invalid Host/Origin and requires a random per-launch bearer token. Secret model credentials stay in Python.
- Frontend renders untrusted content as text. Native bridges expose directory selection and project-bounded editor opening only.
- No modification or staging of unrelated existing changes. Installer artifacts and platform release verification are M3 work.

## Review Focus

- Branch B must not receive branch A's later messages or task requirements.
- A stopped run must release its project lock only after async children finish, and queued work must remain paused.
- Reusing a request ID with a different payload must fail; expired approval IDs must never act on another run.
- A missing checkpoint or incomplete tool exchange must disable exact fork without damaging the source.
- Stale layout revisions, malicious HTML and cross-origin requests must fail safely.
