# 完全访问、运行轨迹、子代理与正文复制验收

日期：2026-10-07。状态：代码修改完成；本地回归通过，真实 API 冒烟有一项外网 DNS 失败，未计为通过。

## 1. 完全访问模式

```bash
nailong --dangerously-skip-permissions
# 指定项目
nailong --project /绝对路径/项目 --dangerously-skip-permissions
# 无界面模式
nailong --dangerously-skip-permissions -p "执行当前任务" --output-format json
```

- 本次进程允许文件工具访问任意文件路径，跳过权限配置规则和逐项审批；不写入项目设置，下一次普通启动恢复默认策略。
- 网络请求通过现有 `run_command` 执行，Agent 不设置网络目标白名单。实际访问仍受系统账户权限和系统网络约束。
- 只读计划、审查和子代理继续只读。版本冲突检查、输出限制和 API 密钥值脱敏继续生效。
- 项目外文件可读取、编辑和新建。修改会记录到运行事件；项目内验证不能证明项目外修改已验证，交付判断不会因此标成已验证。
- `--permission-mode` 与此参数互斥。已用已安装的 `nailong --help` 核对入口参数。

## 2. 可观察的运行轨迹

```text
/trace
/trace export
/trace export .nailong/exports/run.jsonl
```

复用会话事件日志，提供最近一轮的模型请求、用量、工具执行、审批、错误、子代理预算和交付状态。导出为 JSONL，包含事件顺序、派生轮次 ID、可确认的调用关联及已有结果引用。

导出省略用户和模型正文、原始工具参数、工具输出与差异正文，不包含模型私有思考。缺失的关联标为未知；时间顺序不能证明因果关系。专用 `/trace export` 的输出路径限定在项目内，完全访问模式也采用这一导出约束；默认放在 `.nailong/exports/`。

## 3. 子代理错误原因与修复

原先子代理使用较大的主代理提示词与工具清单；预算准入按保守输入上界及输出额度预留，并发请求临时占用同一共享预算，后续读取结果又继续增大请求。这会在实际已消耗 token 远低于 30,000 时停止调研。

本次修正：

- 使用独立、精简的只读调研提示词，保留 5 个读取与搜索工具。
- 并发预留等待其他请求结算；有完整用量时按真实 token 扣账，用量未知时按预留值计费。
- 默认子代理输出上限从 4,000 降为 1,000，并预留一份最多 512 输出 token 的最终回答请求。
- 预算不足以继续探索时，以预算内证据节选收尾；最终请求禁用工具，服务端仍返回工具调用时也不执行。
- 同一轮内不重复执行已因预算失败的相同委派，预算诊断写入事件轨迹。
- 简单项目介绍或解释由主代理使用核心只读工具直接回答。复杂或用户明确要求委派的任务可继续使用子代理。

真实 API 并发场景中，两个子代理均成功回答，实际合计 10,544 token，30,000 共享预算剩余 19,456，无预算失败。

## 4. TUI 正文复制与展示

- 鼠标直接拖选任意中英文文字，显示选区，`Ctrl+C` 复制，`Esc` 取消选区。
- 有选区时复制不会停止任务或清空输入；后台继续运行，取消选区后显示最新正文。
- macOS 使用原生 `pbcopy`，其他终端发送 OSC52 请求；OSC52 无成功确认。`F7` 可打开只读 Markdown 原文快照作为备用。
- 工具详情在对话内展开，再次点击收起；`Ctrl+O` 控制工具组。模型列表更紧凑，未知用量明确显示为不完整。
- macOS 生产复制方法实际写入测试文本，`pbpaste` 读回完全一致，并恢复原剪贴板。真实终端窗口的拖选到粘贴整条操作链未做人工验证；选择、高亮与运行中复制由 Textual 回归覆盖。

渲染与选择验收见 [正文选择与界面可读性验收](2026-10-06-transcript-readability.md)。

## 5. QA 关联修正

状态查询及暂停后的问候使用本地结果，不改变原任务需求版本、暂停状态或已有证据。明确继续原任务保留已有需求与证据。重复只读探索检测支持交替调用；编辑、命令及错误会阻断只读重复判定。最后一次主模型调用用于汇总已有证据，不执行新工具。
