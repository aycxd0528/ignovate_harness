Ignovate v1.3.0 预发布版：新增桌面首次使用引导，补齐普通会话的原生自动验收链路。

本版本用于体验和评测，尚未达到工业级稳定交付标准。首次使用引导已通过 Mac、Windows 安装版检查；较早冻结版本 601bdd9 的六次真实任务评测中，独立功能验收通过 5/6，完整交付验收通过 0/6。该评测未包含后续文件覆盖判定修复和引导功能，不能据此推断本发布版本的通过率；修复后的同条件重复评测尚未完成。失败记录保留，不作为正式稳定版发布。

- 新电脑首次打开桌面版时显示四步使用引导：欢迎、工作区、模型连接、开始。使用实际 React Bits Stepper 动画，支持返回、跳过、重新打开、深浅主题及减少动态效果。配置完成状态保存在本机，示例任务只加入草稿。
- 新安装不再先弹出缺少说明的目录对话框；从引导中选择项目，后续启动记住已选择且仍存在的工作区。路径失效时进入空白起始目录并引导恢复。

- 普通工程任务可将有效用户要求、覆盖路径与实际验证命令绑定。交付前由原生验证器执行，记录当前任务修订、输入指纹、命令结果和证据引用。
- 区分代理声明的覆盖范围、真实执行证据与独立功能验收；模型文字、普通命令成功或流程配置本身不等同于用户确认。
- 保留项目原有检查及必需验收，新增要求、输入或项目验证配置变化后使旧证据失效；普通任务转持续目标时保留既有检查。
- 自动验证遵守工具限制、命令审批与生命周期钩子。实时显示已完成检查；取消、拒绝、失败和后置钩子中断均保留实际执行记录。
- 历史结果可按引用恢复；费用压力下可归档已结束轮次，在保持严格预算及真实输出上限的前提下重试准入。预算停止时保存任务和本地证据报告，不自行重置额度。
- 修复任务目录路径未规范化导致的目标交接异常，并保留最新 main 的 Windows、关闭清理和桌面运行时修复。
- 修复“请接手”“继续完成交付”“请按契约完成审查”等实施请求被拒绝绑定验收的问题，并保留查询、只读、禁止执行和历史说明的边界。真实任务评测及其限制见 [评测记录](https://github.com/aycxd0528/ignovate_harness/blob/v1.3.0/docs/REAL_TASK_EVALUATION.md)。
- 修复宽范围任务中按具体文件绑定的有效原生证据无法满足交付判定的问题；保留需求关联、当前版本、完整执行证据和全部修改路径的覆盖检查。

macOS 安装包为 `Ignovate-1.3.0-macos-arm64.dmg`，适用于 macOS 13 及以上 Apple Silicon Mac。内置 Python 3.11、固定依赖与 ripgrep；打开 DMG 后将 `Ignovate.app` 拖入 Applications，首次启动选择工作区并配置模型。现有配置、会话和工作区数据保留。

安装包使用 ad hoc 本地签名，未经过 Developer ID 签名或 Apple 公证；首次打开方式见[安装文档](https://github.com/aycxd0528/ignovate_harness/blob/v1.3.0/docs/INSTALL.md)。发布资产同时提供 SHA-256 校验文件。单次测试通过不构成通用任务成功率或生产 SLA 承诺。
